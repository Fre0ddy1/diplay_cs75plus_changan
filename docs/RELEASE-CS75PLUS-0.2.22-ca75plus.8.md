# diplay-cs75plus 0.2.22-ca75plus.8

适配2022款第二代长安CS75PLUS／梧桐S311_MCA，基于上游0.2.22。

- 支持CarPlay导航接入实体HUD，保留导航保持与结束清除。
- 改善仪表自动全屏、首次CarPlay画面接管及重连恢复。
- 媒体播放和按键控制采用CarPlay链路，支持方向盘上一首、下一首、播放/暂停。
- 优化音频焦点处理，微信语音结束后音乐自动恢复已在本车实测。
- 保留媒体/导航独立音道配置、导航期间音乐降音及结束恢复。
- 精简常驻日志，保留关键事件；单份常规会话日志256 KiB，保留两份历史并限制写入队列。
- 更新项目说明，GitHub与Gitee定制支线同步。

## 注意事项

**务必关闭原车高德的「自动进入巡航」开关，以免影响HUD显示。**

同包名、同白名单签名，可覆盖升级并保留数据。仪表投屏时保留原厂高德后台、关闭ADB；手机导航时原厂高德保持未导航、未巡航。其他通用功能和配置参照上游说明。

附件提供APK、SHA256SUMS和构建身份信息。应用名`diplay-cs75plus`，包名`com.shihab.diplay.hudtest`，内部版本50。

# 74版：展示与提示修正

基于73版 `34be049fdacbdc45075216a62fdaef94acf93119`，版本 `0.2.22-ca75plus.32` / 内部74。
本轮仅吸收第一类展示、参数显示及文案修正。公版参考固定为 `v0.2.22` / `28d6002ba00320f0ba745212160b08759e4f60b9`，没有合并整个公版分支。

## 改动

|范围|公版参考PR|本版实现与边界|
|---|---|---|
|连接阶段|#624|按现有CarPlayStatus直接选择本地化文本，不再用中文等译文匹配英文关键词。原始诊断描述、连接状态、重试及恢复条件不变。网络就绪提示不显示SSID或地址。|
|空热点名称|#726|首页和连接提醒使用不带名称的通用说明；有实际名称时继续显示原名称。不改热点读取、校验、启动和保存。|
|手机名称|#778|未选择手机时不显示虚构的名称；名称缺失或全空白时使用本地化通用名称。真实名称和蓝牙地址保持原值。|
|有线首页|#744|已有有线会话时标题显示USB并隐藏无线热点说明。断开后的主卡仍对应原来的无线连接按钮；未复制该PR里的USB协议改动。|
|音频说明|#842的文案意图|只澄清本线已有媒体按键、焦点、蓝牙媒体设置的区别，修正“导航播报不会压低音乐”的过时文字。公版BYD通话/Siri专用开关在本线没有同等入口，不复制支持承诺或控制实现。|
|ADB未响应|#1045|在原有未响应结果出现时，只读USB调试标志，区分已开、关闭、无法读取。明确USB开关不代表网络ADB可用；不改变LocalAdb结果、探测次数、授权及开关操作。|
|VPN缺少授权页|#1096的提示部分|保留原有有线回退，仅补准确提示及设置页手动命令。命令使用实际包名，只显示，不执行appops、不自动授予权限。|
|物理参考尺寸|#1032的显示部分|显示真实保存的毫米数和宽/高参考方向；不落在预设时将原选择器明确标为“最接近的预设”。报告不再把真实值替换为近似枚举。不改变范围、步进或保存回调。|
|分辨率|#923的显示部分|区分保存比例与带时间的最近一次请求像素；已有中间比例可正确显示，不自动保存或重连。未知历史格式显示无记录，不伪称当前实测值。HEVC及全屏预览文字本地化。|
|录音时钟标签|#963的标签部分|在原有开始/汇总诊断里标注协商RTP时钟及步进。不增加统计频率、测量循环或录音，不改采样率、音源、编码和分包。|

PR来源：`https://github.com/shihabal3amri/DiPlay/pull/<编号>`。采用差异适配，不代表整项PR原样合入。

## 保留的定制行为

- 全部 `customizations/` 文件保持73原文，包括HUD、仪表、高德前置、原车媒体卡、CarPlay音频、目标手机蓝牙媒体租约、退出锁、热点开启、界面样式和精简日志。
- 连接、投屏及音频配置方法保持原逻辑；共享协议/媒体生产文件只有 `MicrophoneCaptureStats` 的诊断元数据变化。
- 设置默认值、物理尺寸算法、分辨率请求算法、权限清单和音频路由不变。车道及原生采样率开关仍默认关闭。
- 本版不引入设置搜索、备份、网页取日志、更新器、灯光接口或新的后台服务。

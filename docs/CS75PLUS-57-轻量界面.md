# 57候选：保持视觉，减少重复工作

用户明确选择只调整配色，保留页面结构，并以车机流畅性优先。因此沿用56已完成的半透明配色与现有布局，不重做导航结构、控件交互或整套iOS界面，不增加动态折射及进出场动画。

57=`0.2.22-ca75plus.15`，本轮变化集中在glass-ui：

- 同尺寸首页、设置页及CarPlay菜单复用一份柔化背景像素，不重复生成和分配相同背景。共享缓存仅保留一个当前尺寸条目；单个像素缓冲仍限制在640×360，1920×720页面通常为480×180。尺寸不同而旧页面仍可见时，不手动回收它正在使用的像素，待引用释放后由系统回收。
- 按钮内层高光的矩形与圆角在尺寸变化时计算，绘制时复用，去掉draw路径中的临时RectF分配。颜色和绘制顺序不变。
- 背景的柔化仅在缓存未命中时进行一次，正常绘制只显示缓存图。不截取屏幕、不实时模糊CarPlay、不增加后台刷新循环。原生点击反馈和已有轻量高光保留。

新增回归检查同尺寸共享缓存、单缓冲容量，以及替换缓存后旧页面仍能安全绘制。另用实际Activity截图与56逐像素对照，排除版本文字变化后检查外观是否保持。截图、编译与回归不能替代实车帧率测量；此处只确认减少了源码中的重复生成和临时分配，不宣称具体FPS或耗电改善。

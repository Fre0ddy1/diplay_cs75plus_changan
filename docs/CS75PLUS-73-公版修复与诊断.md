# 73版：公版修复与有限诊断

基于72版 `56c7ad50d87f6b2e2b0878086cfbccfa2140ad7c`，版本 `0.2.22-ca75plus.31` / 内部73。
公版来源固定为 `shihabal3amri/DiPlay v0.2.22` / `28d6002ba00320f0ba745212160b08759e4f60b9`。
本轮只吸收上轮建议的8组，按现有维护线做差异移植，没有合并整个公版分支。

## 适配边界

- 保留72仪表/原厂高德联动开关默认关闭，HUD独立，车道及采样率选项默认关闭。
- 保留CarPlay主音频资源协商、蓝牙媒体音频租约、按键防重复、原车媒体卡及HUD模块。
- 未吸收评估组的Android9 TCP判死、热点接口选择、有线补启动、首帧后启动仪表、导航焦点、缓冲配置和视频优化。
- 类型化异常仍是IOException，只改变提示，不更换热点/USB重试策略。当前没有公版完整WirelessStartupPolicy/ManualHotspotReadiness，未为诊断而引入这些状态机；本线没有的“指定热点接口”错误不虚构检测。
- 主屏首帧提示只证明接收端尚未见到主屏数据，不证明手机故障或仪表故障，也不自动重启设备。
- 崩溃记录不覆盖native崩溃、系统强杀或掉电。麦克风上下文读取受系统可见范围限制，空列表不证明没有其他应用使用麦克风。
- 未执行ADB、安装或车机修改。本地回归和编译不等于实车验收，也不代表完整Apple/MFi认证。

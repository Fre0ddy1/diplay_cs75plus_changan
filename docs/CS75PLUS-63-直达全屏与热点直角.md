# 63候选：直接全屏、热点自动填写、直角界面

基于62版维护线，不包含60/61公版吸收。61支线继续按用户要求暂停验证。本轮不连接ADB、不安装或修改车机设置。

## 直接全屏

原先初次激活、来源交接、保留通道静默恢复和重申中的`setMode(1)`后再`setMode(3)`，在开启长安自动全屏时统一跳过前者，通过通用`initialProjectionLayout`获取模块偏好。未注册模块或明确关闭自动全屏时保留原路径，不将车辆条件写进通用API。

本次只移除DiPlay主动发送的小屏步骤。保留已有全屏握手参数、来源交接、窗口/会话隔离和3次有限恢复，不猜测厂商滑动参数，不改成无限发送。固件自己上报小屏时仍按原恢复策略处理，不能由离线测试保证实体屏幕绝不短暂出现小屏。

回归覆盖冷激活和来源交接、保留通道与重申，以及禁用自动全屏和未注册定制模块的兼容路径。62的早到确认、延迟确认、过期窗口等用例继续保留。

## 热点自动填写

`hotspot-startup/SavedHotspotReader`只读Android9原车已有AP配置，不启动或关闭热点、不扫描、不改系统配置、不调用ADB。通过通用`platformHotspotCredentials`提供已核验名称和密码；凭据对象的toString隐藏全部内容，不记录真实密码。

首页“车机热点详情”和连接界面热点设置打开时各读取一次，填入SSID、密码及对应开放/WPA2类型，频段和信道使用自动。继续沿用保存/取消：打开页面不会直接覆盖已保存数据。连接其他Wi-Fi的表单不读取原车热点。

接口不可用、权限拒绝、未知安全类型、缺少或被掩码的密码、无效配置均回退原手工设置。只有确认开放的网络才能导入空密码。保留名称和密码里的空格/引号，不把系统占位符当实际凭据。实际读取权限仍需上车验证。

62版旧实车日志已有`Manual hotspot configReadable=false`，但没有记录该次失败的异常类型，不能确定是接口、权限还是空配置。本次同样使用框架getter，不能仅凭模拟测试宣称已解决本车读取限制；新增诊断只记录失败类别，不记录名称、密码或异常消息。没有新增权限授予或系统隐藏接口豁免。

## 直角

保留轻量磨玻璃配色和静态背景，主页面板、按钮、选择项、连接菜单、视频控制按钮与自绘导航卡片改矩形；接收端导航视频卡及桌面地图悬浮窗去掉圆角裁剪。主CarPlay视频本来就没有本地圆角遮罩，不添加裁切或缩放来掩盖iPhone视频内部的圆角。

iPhone自己绘入视频的路牌/卡片圆角属于远端画面，本地边框样式不能将其无损改直角。回归渲染实际首页/设置页，并核验本地面板与按钮Outline半径为0。

## 验证安排

先检查上述受影响路径，再进行候选定稿的一次完整定向回归、构建、lint、签名和公开树检查。失败记录保留，不删除、跳过或改弱62已有用例；实车结果另记，不用离线通过代替硬件验收。

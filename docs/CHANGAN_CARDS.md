# 仪表卡片内容选择修复

版本 41（`0.2.21-ca75plus.5-hud-test`）使导航卡片组遵守“仪表盘显示内容”。只有选中“地图和自定义卡片”且显示导航流时，DiPlay 才叠加转向、到达、车道、路名和出口卡片。地图默认、原生转向卡和原生地图加转向卡均不叠加这一组；每张卡片仍需要有效数据且自身开关开启。歌曲信息由独立设置控制。

该问题在接手前的 `bd30e99be09f2dfc32e0ea7b21d40b2a1e8adb8e` 累计长安改动中引入，`9af1457` / 0.2.21 已包含。`ClusterMapPresentation.kt`、内容枚举和保存方法从 0.2.21 到版本 40 没有变化；不能据此归因为本次 HUD 定制直接修改了卡片路径。旧渲染只判断导航流/整机镜像和单卡开关，遗漏整个内容选择。

内容开关在窗口创建及设置刷新时缓存，导航更新不会每秒读偏好。设置或模式变化时恢复缓存指引，再统一执行内容/单卡开关，确保切回自定义时无需等待手机下一次更新，同时不会显示缺少数据的空卡片。

回归使用 SDK28 的真实 Presentation 和卡片视图，覆盖四种内容、后续导航更新、缓存恢复、整机镜像及单卡关闭/缺失数据。完整验证记录在 `customizations/VALIDATION.md`。结构检查也记录这个入口，合并上游时必须重新核对，不能用旧显示文件覆盖新版。

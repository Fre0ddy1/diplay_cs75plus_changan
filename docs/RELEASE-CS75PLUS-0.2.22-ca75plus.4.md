# diplay-cs75plus 0.2.22-ca75plus.4

面向2022款第二代长安CS75PLUS／梧桐S311_MCA的首个本仓库发行版，内部版本46。基于Gitee长安定制上游0.2.22及本项目45版HUD、仪表修复。

## 功能

- 手机CarPlay导航接入实体HUD，显示转向、距离和路名；不依赖高德助手。
- 保留静止及应用后台的HUD指引，导航结束后清除。
- 仪表自动全屏、CarPlay重连恢复与旧回调隔离。
- “仅地图／地图和自定义卡片／Apple完整导航”内容选择，保留上游原生指令卡视频。
- HUD与仪表恢复策略独立模块化，便于继续合并上游代码。

## 本次发行变化

- 应用桌面名称统一为 **diplay-cs75plus**。
- 版本号更新为 **0.2.22-ca75plus.4（46）**。
- 更新本仓库车型、功能、升级条件、模块结构及验证说明。
- 功能逻辑沿用45版，本次不调整媒体12／导航10或音量参数。

## 安装与使用

- 下载附件中的APK；原项目同签名测试版可直接覆盖升级，保留应用数据与CarPlay配对。
- 包名仍为 `com.shihab.diplay.hudtest`，沿用原白名单签名。
- 本车仪表投屏需关闭ADB，并保留原厂高德在后台；车机高德保持未导航、未巡航。
- **请关闭原厂高德自动巡航**：原厂巡航与HUD仍存在竞争，可能反复闪烁，本版未宣称彻底解决。
- 原车速度表上方的转向卡保留；“仅地图”不关闭实体HUD或原车仪表卡。

45版已在本车观察到HUD、结束清除、后台保持、内容选择及关闭ADB后自动全屏的成功样本；重连长期稳定性仍需持续观察。46版仅更新名称和发行元数据，未另行安装到车机验收。

## 验证与来源

发行APK沿用45版未混淆构建方式和诊断能力。构建、定向回归、lint及签名核验结果见[验证记录](https://github.com/Fre0ddy1/diplay_cs75plus_changan/blob/v0.2.22-ca75plus.4/customizations/VALIDATION.md)。全量历史测试仍保留上游既有失败记录。

# diplay-cs75plus 0.2.22-ca75plus.33（75）

适配 **2022款第二代长安 CS75PLUS／梧桐 S311_MCA（Android 9）**。本次发布当前 0.2.22 定制维护线的最新基线，沿用已完成白名单签名的 75 版 APK。

## 本次基线包含

- **实体 HUD 导航**：显示 CarPlay 导航的转向、距离和路名；静置及应用后台保持指引，导航结束或断开连接后清除。
- **仪表投屏**：支持自动全屏、视频就绪后接管 CarPlay 画面及重连恢复；补齐发送成功但原车状态未确认时的有限重试和手动开屏恢复。
- **仪表功能按需启用**：设置→仪表盘的“连接手机时拉起原车高德”与“自动飞屏”联动，默认关闭。需要仪表投屏的车型请手动开启；HUD 单独控制。
- **仪表内容选择**：支持仅地图、地图与自定义卡片、Apple 完整导航；保留 CarPlay 视频自带的转向卡。音乐封面、信息及自定义卡片默认关闭，按需开启。
- **CarPlay 音频和方向盘按键**：音乐、导航播报及媒体控制使用 CarPlay 链路；统一播放、暂停和切歌入口，避免应用内部重复处理造成一次按键切两首，移除逐次按键前的交接等待。
- **目标手机蓝牙媒体管理**：设置→连接新增联动开关，默认开启；连接期间关闭所选手机的蓝牙媒体音频，断连或正常退出时恢复连接前状态。
- **原车媒体卡**：接入歌曲信息、封面、进度和播放状态；暂停时保留当前曲目信息，断开 CarPlay 后结束上报。
- **音频恢复**：保留媒体与导航独立音道设置、导航播报降音及结束恢复；微信语音结束后恢复音乐的行为已有本车实测。
- **启动和退出**：增加热点状态检测、开启及结果提示，读取可获取的原车热点配置；提供退出应用入口，退出后保持停止，直到手动打开。
- **轻量界面**：首页及设置使用半透明配色与圆角控件，优先保证车机流畅度；CarPlay 画面边界使用直角配置。
- **吸收公版修复**：选择性吸收触摸、多点输入、协议边界、按需日志、音乐时钟、麦克风、连接恢复保护和显示提示修正，保留长安 HUD、仪表、音频及媒体卡模块。
- **精简诊断**：常规会话日志单份最多 256 KiB，保留两份历史，写入队列有上限；补充连接失败和进程退出等关键诊断。

## 安装与使用

1. 下载附件 `diplay-cs75plus-0.2.22-ca75plus.33.apk`。包名为 `com.shihab.diplay.hudtest`，沿用本项目白名单签名；同签名版本可覆盖升级并保留数据、配对和设置。
2. **务必关闭原车高德的“自动进入巡航”开关，以免影响 HUD。** 手机导航时，原车高德保持未导航、未巡航。
3. 使用仪表投屏时关闭车机 ADB；在设置→仪表盘手动开启高德／自动飞屏联动，并让原厂高德留在后台。
4. 车道数据接收、导航语音高采样率、通话原生采样率等实验项均默认关闭，常规使用请保持关闭。
5. 其他通用功能和配置参照 [DiPlay 公版](https://github.com/shihabal3amri/DiPlay)及[长安定制上游](https://gitee.com/jiuyueji/diplay_changan)。

## 构建核验

本次复用原 75 版签名 APK，不重新编译。签名、版本、源码输入和附件 SHA-256 已复核；原构建的 758 项定向测试中 757 项通过，保留 1 项既有设置页 UI 测试失败，新增／改变的失败为 0，Lint 错误为 0。75 版新增仪表恢复修复尚待实车回归，不将本地验证写成实车验收。
